# Case Study Images

Estructura de carpetas para imágenes de cada proyecto y etapa.

## Cómo usar

1. Crea una imagen para la etapa del proyecto
2. Guárdala en la carpeta correspondiente:
   - `src/assets/case-studies/[proyecto]/[etapa]/[nombre-imagen].png`

## Ejemplo

Para una imagen de wireframes de Tadiclick:
```
src/assets/case-studies/tadiclick/wireframes/pantalla-login.png
```

Para una imagen de discovery de VAST:
```
src/assets/case-studies/vast/discovery/brief-proyecto.png
```

## Etapas disponibles

1. `discovery` - Descubrimiento
2. `ux-research` - Investigación UX
3. `define` - Definir el problema
4. `ideate` - Ideación
5. `ia` - Arquitectura de Información
6. `wireframes` - Wireframes
7. `ui-design` - Diseño UI
8. `prototype` - Prototipo
9. `testing` - Testing de Usabilidad
10. `iteration` - Iteración
11. `handoff` - Handoff a Desarrollo
12. `followup` - Seguimiento
